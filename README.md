# 你是哪一种打工牛马？

一个纯前端、无需数据库、无需 LLM 的职场人格趣味测试 MVP。

## 当前功能

- 15 道职场情境题
- 12 种打工牛马人格
- 6 个评分维度：上进心、服从指数、摸鱼效率、职场生存力、跑路冲动、AI 外骨骼
- AAA / AA / A / BBB / BB / B / CCC / D 牛马评级
- 随机“牛马评级机构”毒舌评语
- Web Share API / 复制结果分享
- 移动端适配
- 纯 `index.html`，没有后端依赖

## 本地预览

直接打开 `index.html` 即可。

## GitHub Pages

Repository Settings → Pages → Build and deployment → Source 选择 `Deploy from a branch`，Branch 选择 `main` / `(root)`，保存即可。

上线后可以继续增加：结果卡导出图片、第二套“老板最怕的员工”测试、AI 减负检测、更多插画和分享裂变入口。
